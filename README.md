## Perfil profissional

Sou **Full Stack Software Developer**, formado em **Análise e Desenvolvimento de Sistemas pela Universidade Católica de Brasília**, com atuação orientada à construção de soluções que conectam back-end, front-end, aplicações mobile, automação de processos e análise de dados.

Minha experiência prática está concentrada em transformar rotinas operacionais em produtos confiáveis: aplicações corporativas, integrações com ERP, dashboards gerenciais, sistemas web e aplicativos mobile. Trabalho com uma visão de produto e negócio, priorizando **segurança, rastreabilidade, qualidade de código, documentação e impacto mensurável**.

Atualmente, estou ligado à **Sol Atacadista da Tecnologia**, em Brasília, e continuo aprofundando conhecimentos em arquitetura de software, inteligência artificial, LLMs, RAG e engenharia de dados.

## Princípios de trabalho

```text
Problema real  →  Requisitos claros  →  Solução simples e segura
      ↓                                      ↓
Impacto no negócio  ←  Métricas e documentação  ←  Testes e observabilidade
```

- Entender o processo antes de automatizá-lo.
- Projetar para manutenção, não apenas para a primeira entrega.
- Tratar segurança e rastreabilidade como requisitos do produto.
- Documentar decisões para que o conhecimento permaneça no time.
- Usar dados para validar resultados e orientar a evolução.
